Noticings as chips beside search

The real Bengaluru layer — 66 places, 335 noticings — on a pretend map. The search box sits where the editor already puts it, top-centre over the map; the chips are one thin row underneath, and that is the whole footprint. A chip is a real noticing, exactly as someone wrote it. Tapping one just runs the search that already ships: same matching, same hiding of pins, same count. This page matches by words alone; the live atlas also matches by meaning, so a real tap lights these places and often a few more (that part is an estimate — the rest of this page is measured).

The reader's side — tap a chip, or type

Tap a chip: the word lands in the box, pins that don't match go away, the count reports. Tap it again — or clear the box — and the map comes back. Type your own words and the chips simply stand aside; a chip is a hand that types for you, so chip and typed search can never fight. Hover any pin to read its noticings. The small squares beside some pins are the theme badges the map already wears — when search hides a pin, its badges go with it; nothing new to reconcile.

The owner's side — the machine suggests, you decide

Same say you get over themes, but lighter: nothing is invented, so there is nothing to gate. The list below is derived by counting alone — each noticing ranked by how many places it lights through the existing search, skipping ones that would secretly act as a whole category (urban-nature lights all 20 Nature places because the search matches the category word inside it), and skipping near-repeats. Untick what bores you; add what you love — the one-of-a-kind noticings are where the delight lives, and only you can rank delight. Everything you change here updates the row on the map above, live.
